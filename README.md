# Atlas

Atlas is an AI personal-finance dashboard that gives you a clear view of your money in one place. Explore your net worth, accounts, transactions, investments, spending, assets, and liabilities.

Atlas is currently a frontend-only project using React 19, Vite, Tailwind CSS v4, and shadcn/ui. It uses mock data for now. Future plans include a Node.js API, Postgres, Plaid bank connections, daily net-worth snapshots, and an AI layer for asking questions about your finances.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in your terminal.
